# Swapper source provenance

The base is [DLSS5-Swapper v2.2.7](https://github.com/rakanki911/DLSS5-Swapper/tree/3b3b0efb5472df7fc806d7aff31c1d95819500c5), commit `3b3b0efb5472df7fc806d7aff31c1d95819500c5`. The original `LICENSE`, `overlay/LICENSE` and `THIRD_PARTY_NOTICES.md` are retained. Rakan Alkhaldi's MIT copyright and the included DLSS5-Autopilot MIT notice are unchanged.

The five application changes were read back from the independently validated integration ASAR `5cb38cf6052e726e36566edea1899f0d176fec2109bfc169cce75067fb06f0f4`: `main.js`, `src/core/backend-manager.js`, `src/core/wuwa-install.js`, `src/renderer/renderer.js`, and `src/overlay-bridge.js`. The public source then replaces the private machine target with explicit selected-root recognition, enforces the locally generated native target metadata, separates the fork's name/application ID from upstream, and keeps the intentional local update policy from displaying a failed generic update check. This public source is a subsequent source revision, not a claim that its build is byte-identical to the earlier machine-specific executable.

The focused IPC/idle tests are adapted from the validated installer test harness. They use temporary fixtures, real main IPC and real transaction/backup code. Build/import/verification scripts are source-only and take explicit local inputs. Historical visual demo GIFs/screenshots and the inherited documentation folder are omitted; source build assets remain. Original general-purpose Swapper features outside the dedicated WuWa branch have not been requalified by this fork.

The dedicated production F8 implementation lives in the sibling overlay source package. That package derives from Swapper v2.2.9 and must retain its own upstream MIT/third-party notices, ReShade license and ImGui license. No v2.2.9 overlay source was silently inserted into this v2.2.7 Swapper subtree. The native package has its own source/dependency provenance and notices. All three packages use ABI1 with state 376 bytes and command 24 bytes.

Binary reference hashes in `SOURCE_PROVENANCE.json` identify the previously validated private build only. They are public digest references, not downloadable binaries or redistributable NVIDIA components. A native rebuilt for another exact target naturally can have a different hash. Build metadata containing actual game paths, imported component files, cache directories and local verification/deployment reports are excluded from the source release.

The original third-party notice describes the upstream application's optional runtime components. This source-only distribution contains none of those compiled dependencies. Users must respect each component's own license when obtaining, building, using or separately distributing a local build.
