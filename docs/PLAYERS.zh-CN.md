# 玩家指南：一起减少显卡负担

这个项目希望让玩家在满意的画质下，减少开启神经渲染后的额外计算、发热和风扇压力。鸣潮是目前的起点。你可以通过实际使用、设置经验、画质观察和问题反馈参与，不必先懂源码。

## 目前能拿到什么

GitHub 源码仓库提供源码、构建方法和测试记录，不含二进制。[Releases](https://github.com/belugaaaaaaaa/DLSS5-Swapper-WuWa/releases) 提供 **轻量部署助手预览版 `v0.2.0-deployer-preview`**，为鸣潮提供无需编译的安装入口。下载 `DLSS5-Swapper-WuWa-v0.2.0-deployer-preview.zip`，使用步骤与验证范围见 [部署说明](DEPLOYMENT.zh-CN.md)。已有本地安装版本获得真实鸣潮用户验收，用户确认显卡“起飞”的体验问题改善，见 [实测记录](USER_VALIDATION.zh-CN.md)。

普通玩家使用部署包即可，不需要先学会编译。工具会绑定你明确选择的鸣潮主程序路径，自动准备并校验所需组件；已有官方 v2.2.7 原版 EXE也可作为组件来源。如果你愿意自行构建，使用 [原生插件构建说明](../build/README.md) 与 [Swapper 构建说明](../swapper/BUILD.md)。

原版 Swapper 与本项目适配是两个版本。轻量包不包含 NVIDIA 模型/运行库、原版 EXE或游戏文件，外部组件在你的电脑上取得并遵守各自许可。过去的个人完整 Swapper 改版包不公开。

## 下载部署包后怎样使用

1. 关闭游戏和启动器，解压 Releases 的部署助手 ZIP，双击根目录 `Start-Setup.cmd`。选择包含 `Wuthering Waves Game` 的鸣潮根目录，查看并同意列出的许可，点击“一键安装 / 修复”。完整过程见 [部署指南](DEPLOYMENT.zh-CN.md)。
2. 安装完成后启动鸣潮。使用默认 F8 打开原生面板；安装后无需让 Swapper 窗口常驻。
3. 查看面板中的实际运行状态。NR 开关、每次刷新/缓存模式和处理比例可以帮助你探索画质与负担的取舍。已有设置会保留；命令生效要以状态回读为准。
4. 先在熟悉的场景观察人物、暗部、运动边缘和 HUD，再决定是否保留这组设置。需要卸载时，关闭游戏，在助手中选择原目录并点击“卸载鸣潮插件”。个人调节记录保留用于之后重装。

缓存是减少重复计算的一种尝试。它在符合条件时复用 NR 结果；条件不符合时继续正常 NR。某些被拒绝复用的像素会使用当前 DLSS 图像，因此运动中的拖影、闪烁和局部增强变化值得反馈。

## 哪些反馈最有帮助

没有测量工具时，描述风扇感受、画质是否满意、哪些场景更顺畅或更糟，就已经有价值。请把主观感受写成感受，缺少的数据标为未知。

如果能做对照，在同一场景保持分辨率、游戏画质、DLSS/插帧和帧率上限一致，分别记录 NR 关闭、每次刷新和缓存模式。记录使用的版本与设置，也注明帧率是否包含生成帧。详细方法见 [游戏对照测试](GAME_VALIDATION.zh-CN.md)。

优先记录这些项目：显卡与驱动、版本、场景、设置、实际 NR/缓存状态，以及风扇、功耗、温度、帧时间和画质变化。只有一部分数据也可以提交，不需要为了填表安装额外工具。

通过 [玩家实测反馈](https://github.com/belugaaaaaaaa/DLSS5-Swapper-WuWa/issues/new?template=player-test.zh-CN.md) 分享结果；遇到无法运行、安装失败、拖影或闪烁，使用 [问题反馈](https://github.com/belugaaaaaaaa/DLSS5-Swapper-WuWa/issues/new?template=quality-or-bug.zh-CN.md)。截图遮住 UID 和个人信息，日志只摘录与问题有关的内容并去掉个人路径。

## 我们怎样判断改进

同样满意的画面下，少一些额外计算、功耗、风扇压力或帧时间波动，都可能是有价值的改进。更多显示帧数也要结合是否插帧、延迟和功耗来看。

不同机器可能得到不同结果。你觉得有效的设置，需要带着适用条件分享；发现没有收益或画质退步，同样能帮助社区避免无效改动。
